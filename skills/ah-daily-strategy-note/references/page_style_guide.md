# Page Style Guide

这个 reference 用来锁定页面风格。
目标是确保每次生成的简报都保持同一套卖方策略页视觉语言，而不是每次重新设计。

## 总体方向

- 券商 / 卖方 / 交易台 briefing 风格
- 强结构，结论前置
- 纸面感明显，默认面向 PDF
- 克制，不花哨，不娱乐化
- 看起来像“可直接发给投资经理”的成品

## 页面尺寸

- 默认按 `A4 portrait` 生成
- 屏幕显示比例要尽量等于打印比例
- 版芯要稳定，避免“屏幕一套、打印一套”

## 配色

默认固定为：

- 背景：白纸或极浅灰白
- 主强调：砖红 / 深红
- 标题底：深蓝灰
- 摘要框：浅蓝灰
- 正文：深灰黑
- 标签色：
  - 默认遵循 A股视觉习惯：红涨绿跌
  - `利好`：红色
  - `利空`：绿色
  - `中性`：蓝灰
  - `暴涨`：亮红
  - `暴跌`：深绿
  - `抗跌`：深红
  - `领涨`：红色
  - `领跌`：绿色

补充要求：

- 指数涨跌幅、个股涨跌幅、板块强弱标签，默认统一按 A股口径显示
- 即使正文同时覆盖港股，也不要切回“绿涨红跌”的国际行情配色

不要：

- 紫色
- 多彩渐变
- 发光按钮
- 互联网产品风的亮色体系

## 版式结构

固定建议：

1. 顶部标题区
2. 核心观点摘要框
3. 指数行情带
4. A股 / 港股双栏分析
5. 市场微观动态
6. 新闻驱动与策略
7. 明日观察 + 数据口径

## 标题系统

- 页面主标题只能有一个
- 英文辅助标签尽量少，不要和中文标题重复表达
- 一级模块标题用深蓝底白字
- 二级小标题用左侧红线或加粗短标题
- 避免同一层级出现 3 套不同风格

## 指数行情带

- 要像交易台快速扫描区
- 优先单行横向排布
- 每个指数只放：
  - 名称
  - 点位
  - 涨跌幅
- 不要在指数区塞长段点评
- 结论性交给后面的分析区

## A股 / 港股双栏分析

每栏固定包含：

- 今日走势
- 热门股
- 领涨 / 抗跌
- 领跌 / 杀跌
- 一句话判断

写法要求：

- 每栏都要有“总判断”
- 热门股用标签 + 涨跌幅 + 原因
- 不要堆纯名单

## 市场微观动态

必须出现，且要像“盘口温度”：

- A股热门股
- 港股热门股
- 领涨板块
- 领跌板块
- 大宗商品跟踪

商品跟踪默认至少有：

- 黄金
- 白银
- 油价

## 标签系统

统一使用中文短标签：

- `利好`
- `利空`
- `中性`
- `盘后`
- `暴涨`
- `暴跌`
- `抗跌`
- `领涨`
- `领跌`

不要发明新标签，避免每期风格漂移。

## 字体与密度

- 标题用有一点“研报感”的中文字体组合
- 正文必须可读，不能为了单页硬把字压到很小
- 如果装不下一页，先删冗余标题、删重复句，再压缩模块间距
- 不要优先靠缩小字体解决问题

## 动效与交互

- 默认无动画
- 不做滚动特效
- 不做悬浮卡片花活
- 若有主题切换，只服务预览，不影响打印

## 绝对不要做的事

- 不要做成 SaaS dashboard
- 不要把页面做成资讯门户
- 不要把每个模块都做成不同组件语言
- 不要出现夸张图标、emoji 主导的视觉
- 不要让微观动态变成股票名单堆砌
